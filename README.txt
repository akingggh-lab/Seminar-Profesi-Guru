WEBSITE SEMINAR PPG — JUMAHIR

Versi ini disesuaikan dengan acuan ZIP yang diberikan: header putih, logo gabungan PPG/LPTK, foto profil berbentuk lingkaran, latar LPTK gelap dengan overlay biru, aksen emas, kartu dosen, dan empat bagian portofolio.

Isi:
- index.html
- style.css
- script.js
- jumahir_profil.png (foto profil dari file acuan)
- logo_gabungan.png (logo PPG/LPTK dari file acuan)
- lptk_bg.png (latar tema dari file acuan)

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html dengan browser.
3. Seluruh gambar harus tetap satu folder dengan index.html.
4. Koneksi internet diperlukan untuk ikon Font Awesome dan Google Fonts.

Catatan:
Tautan Semester 1 dan Semester 2 masih menggunakan URL edit Google Sites yang diberikan. Pastikan aksesnya tersedia bagi dosen penguji, atau ganti dengan tautan publik mode lihat.
